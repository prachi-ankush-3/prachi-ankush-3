<summary><b>⚙️ GitHub Action Setup for Snake Animation</b></summary>

<br/>

The Contribution Trail section above references an SVG generated by a GitHub Actions workflow (based on the popular <code>Platane/snk</code> action). To make it work:

1. Create a new file in this repository at `.github/workflows/snake.yml` with the content below.
2. Push it to your default branch. The action will run on a schedule and on push, generating the SVG and pushing it to an `output` branch.
3. The `<img>` tag in the Contribution Trail section already points to `https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/YOUR_GITHUB_USERNAME/output/github-contribution-grid-snake-dark.svg` — replace `YOUR_GITHUB_USERNAME` with your actual GitHub username once the workflow has run at least once.

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - name: Generate contribution snake
        uses: Platane/snk@v3
        id: snake-gif
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push snake output to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
